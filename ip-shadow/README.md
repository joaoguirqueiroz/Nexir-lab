# IP SHADOW Android — versão experimental

Aplicativo Android VPN WireGuard com interface nativa. Importa perfil .conf individual, guarda configuração com Android Keystore, inicia túnel real e consulta IP público via HTTPS. Não contém servidores gratuitos sem credenciais.

O APK de testes fica em [Releases](https://github.com/joaoguirqueiroz/Nexir-lab/releases/tag/ip-shadow-preview) se o build for concluído. Esta é uma **branch separada** do aplicativo Nexir Lab para publicação provisória; o app original permanece intacto na branch main.

Instalação: baixe IP-SHADOW.apk, permita instalação de APK do navegador e abra o IP SHADOW. Importe um arquivo de configuração WireGuard de um servidor confiável; configure no Android VPN sempre ativa e Bloquear conexões sem VPN.

Cuidado: APK debug e assinatura efêmera, não usar como atualização de produção. Não compartilhe .conf ou chaves privadas.
